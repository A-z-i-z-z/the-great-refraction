# The Great Refraction

A micro-voxel space sandbox about bringing color back to a fading universe. Explore seamless planets and space,
build ships and bases, craft, tame creatures, weave Hue magic and solve Monolith light puzzles.

**Play:** https://a-z-i-z-z.github.io/the-great-refraction/

Works on phone (touch) and PC (keyboard + mouse or gamepad). Use your browser's *Install* / *Add to Home screen*
to get an offline app. Saves stay in your browser.

This repository holds the built web app only.
